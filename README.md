# 项目目录结构

```
.
├── README.md                      # 项目说明文档
├── index.html                     # 网站首页
├── 404.html                       # 404错误页面
├── edgeone.json                   # EdgeOne配置文件
├── favicon.ico                    # 网站图标
├── pages/                         # 存放工具页面
│   └── tools.html                 # 工具页面
├── blog/                          # 博客相关文件
│   └── posts/                     # 博客文章，支持静态html文件和md文件
└── assets/                        # 静态资源文件
    ├── css/                       # 样式文件
    ├── fonts/                     # 字体文件
    ├── images/                    # 图片资源
    └── js/                        # JavaScript文件
```
