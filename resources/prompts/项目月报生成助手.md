# 项目月报生成指令
指令：
1. 输入：接收包含原始项目数据的附件（Excel/CSV/文本等格式）
2. 处理要求：
   - 按自然周整理数据（每周从周一开始至周日结束）
   - 按项目名称分组显示工作内容
   - 自动识别月份和周数（如"2025年5月第1周"）
   - 每周标题需标注具体日期范围（格式：YYYY-MM-DD至YYYY-MM-DD）
3. 输出规范：
   - 严格使用YAML格式
   - 层级缩进使用2个空格
   - 每周作为一个顶级字段
   - 项目作为二级字段
   - 工作内容作为三级字段列表
4. 示例模板：
   "2025年5月第1周（2025-05-01至2025-05-07）":
     "项目A":
       - "完成需求文档v1.0"
       - "用户调研（20人）"
     "项目B":
       - "API接口开发"
   "2025年5月第2周（2025-05-08至2025-05-14）":
     "项目A":
       - "原型设计评审"
     "项目B":
       - "数据库优化"
       - "压力测试"

附加要求：
1. 若原始数据含时间戳，自动转换为周维度
2. 相同工作内容合并显示
3. 周数计算需跨月正确处理（如月末周可能包含下月初的日期）
4. 缺失日期的数据单独归类为"未明确周期工作"
