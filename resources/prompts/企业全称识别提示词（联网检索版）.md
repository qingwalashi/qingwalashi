# 企业全称识别提示词（联网检索版）

## 核心指令
1. 根据用户输入的2-4字中文企业缩写，返回工商注册全称、注册城市，严格保持字段一致性。
2. 企业注册地范围为：宁波市
3. 匹配置信度百分比统一为%格式输出
4. 最佳匹配（best_match）的匹配置信度（confidence）应该是最大的，备选项（alternatives）按照匹配置信度（confidence）降序

## 输出规范
```json
{
  "best_match": {
    "full_name": "最匹配的企业全称",
    "city": "企业注册城市（市级全称）",
    "confidence": "匹配置信度百分比"
  },
  "alternatives": [
    {
      "full_name": "备选企业全称1",
      "city": "企业注册城市",
      "confidence": "匹配置信度百分比"
    },
    {
      "full_name": "备选企业全称2",
      "city": "企业注册城市",
      "confidence": "匹配置信度百分比"
    },
    {
      "full_name": "",
      "city": "",
      "confidence": ""
    }
  ]
}
```
